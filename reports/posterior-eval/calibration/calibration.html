What this means

  • No run yet. The page holds only the mock ladder (src at 8310cb3, 2026-10-30). Run rows drop in once a run has an eval of the current layout (64-injection grid, fdot in place of Mc); the 2026-10-24 dusty-otter-narrow-XS files are kept in data/ but not shown.
  • Every eval source is faint. The mocks ran with visible_snr = 0 (catalogue windows): the draws' median SNR (snr_hat) is at most 2.6, so every injection is in the 0–15 stratum and the loud strata are empty (a dash). Read the ladder as a faint-source ladder; rerun with visible_snr on.
  • Clean marginal SBC proves nothing alone. The prior mock, an identity flow that ignores the data, passes f0, lon, lat, the z± components, TARP, average rank and band depth in the narrow band (fdot p = 0.009 is its only coordinate rejection); in the full band lat (p = 0.016) and Re z+ (0.044) are marginal. What catches it is in data-space-checks; the measured power of each test is in test-power.
  • The ladder behaves as designed. wide and narrow reject f0, fdot, lon, lat, the z± components, the derived ranks, TARP and band depth in both bands. biased (f0 +1σ) rejects every test except fdot (p = 0.58 narrow, 0.86 full); f0 mean rank offset −0.19 narrow, −0.14 full.
  • fisher is not a clean null at this SNR. f0, fdot and f0 ± fdot pass, but lon, lat, the z± components, |z±|, TARP and the joint ranks reject (narrow, 200 injections): faint sources are non-Gaussian in the flow coordinates, so the linearised Gaussian is miscalibrated there. phases-prior therefore cannot be told from it, and loud-floor equals it (its cap starts at source SNR 18.4).
