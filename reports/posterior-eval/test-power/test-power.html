Which errors can each validation test see?

Every test of canna.lisa.validate on an exact null and on known errors injected into the draws: the null column is the test's size, the others its power.

Setting

How often does each test reject, under each error of the draws?

Share of 100-injection chunks (and slots, for per-slot tests) in which a test rejects at α = 0.05, in %. The first column is the exact null: it should read α for the rank tests. Score tests compare each perturbed set's score to the unperturbed draws' (one-sided paired Wilcoxon), so their null column is 0 by construction. toy: linear-Gaussian slots with exact posterior draws; run: one flow draw stands in for the truth, so the null holds whatever the flow's error.

What this means

  • The rank tests hold their size. On the exact null they reject in 2–9% of the 50 chunks on the toy, against α = 5%. No run row yet: it drops in once a run has an eval of the current layout (the 2026-10-24 dusty-otter-narrow-XS files are kept in data/ but not shown).
  • Per-coordinate SBC is blind to whole classes of error. z+ phase or sky from the prior, and dependence shuffled, leave every 1-D marginal exact, so the coordinate ranks reject at the null rate; 10% prior draws reach only about 10%. The data-space ranks (overlap, log-likelihood, own SNR for the shuffle) reject in 97–100% of chunks, and so does the energy score; the CRPS of the affected coordinates catches the phase and sky errors (100%) and 10% prior draws (58–81%), but not the shuffle (4–9%). Posterior = prior passes marginal SBC: a clean rank histogram on its own proves nothing.
  • Mild width errors need the right test. The coordinate ranks catch narrow ×0.8 in 55–67% of chunks and wide ×1.25 in 32–48%, while overlap and the joint log-likelihood catch both every time.
  • An f0 shift of 0.5σ is caught by the f0 rank (99%) and by the log-likelihood (100%).
  • TARP and average rank add little. Per-slot TARP mostly repeats the width tests (81% for ×0.8, 70% for ×1.25). Average rank is the weakest joint test against everything but the f0 shift.
