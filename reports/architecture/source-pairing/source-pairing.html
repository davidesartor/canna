How should a base draw's sources pair with the target's?

Each training path runs from a prior draw X0 to the target X1, source by source. The sources are exchangeable, so which base source goes to which target source is a choice. This page measures the mean squared path length per source, in flow coordinates, under four pairings: both ends in f0 order (what training uses, a sort), the nearest of the S! labellings over all coordinates, both ends loudest first, and a random labelling. No network is involved: it follows from the prior and the chart alone.

Band

Where is the path length?

Mean squared path length per source, split by coordinate group (f0, log ḟ, the two sky coordinates, the two helicity amplitudes z±). Hover a segment for its value.

Which sources pay for a fixed order?

The same length per target source, by its loudness rank (1 is the loudest of the window). The nearest labelling's length is the least in total, not for each rank.

What this means

  • f0 order is the optimal coupling of f0 alone (the monotone rearrangement), so no two paths cross in f0, and it costs a sort. The coordinates it ignores are paired at random.
  • The nearest labelling is the shortest pairing by construction: it minimises the same sum over all S! labellings, at the cost of an assignment per draw. The page measures how much shorter it is, and in which coordinates.
  • Shorter, less crossed paths are an easier target. The straight-path velocity field averages over the paths through each point; paths of exchanged sources crossing each other make that average blur two targets.
