The sampler's self-conditioned velocity of a trained LisaFlow, on fresh training observations at fixed path times t: how much of it moves with the data rather than with xt, and which data bins it is sensitive to. The last card is the velocity probe: whether the network has learned each coordinate and reads the data's phase. The first cards ask where the velocity's information comes from.

How much of the velocity moves with the data, and how much with xt?

Per coordinate, against path time t: the mean square change of the velocity when only the data change (another observation's y, same xt) or only xt changes (another base draw, same observation), each over twice the velocity's variance. A value of 1 is a fully independent redraw; 0 is no dependence. The two need not add to 1 (they are total effects, interactions count in both).

The squared Jacobian of the velocity in the whitened data, summed over channels, as shares of its total per slot and coordinate: on the bins holding of the slot's own source's power, on the other sources' bands, and on the rest. Sensitivity per bin at a distance from the slot's own f0 bin, relative to uniform (1 = uniform; 10 = ten times the uniform density), at the selected t, per coordinate. Rings are 0, 1, 2–3, 4–7, … bins.

What this means

  • No trained run has been measured yet. dusty-otter-narrow-XS (2,000 steps) only checks the pipeline end to end; its numbers describe a network that has barely trained and say nothing about the architecture.
  • Data share near 0 at late t for a coordinate means its velocity there is set by xt alone: the flow has stopped reading the data and only contracts. That is right once xt already pins the source, wrong if it happens before the posterior width is reached (compare the late-time widths in reference comparison).
  • Data share that grows with SNR is expected: a loud source's data says more. A flat data share across SNR, at a t where the posterior is still wide, points at the conditioning path rather than the physics.
  • Own-band share well above its baseline means a slot reads its own source's Doppler band, as the f0 RoPE intends. Own-band share near the baseline (uniform reading) or a large other-bands share means slots read each other's sources, which the slot sorting and match_sources then have to undo.
  • Enrichment that falls off within a few bins of f0 is a local reader; a flat curve is a global one.
